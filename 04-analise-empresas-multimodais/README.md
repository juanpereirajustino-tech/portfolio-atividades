# 04 — Análise de Empresas Multimodais

Análise dos dados de empresas habilitadas para atuar no transporte multimodal.

## Objetivo

Investigar os dados das empresas multimodais e apresentar informações relevantes por meio de análises e visualizações.

## Problema

Organizar e interpretar os dados para transformar registros brutos em informações úteis para análise.

## Ferramentas

- Excel
- Análise de dados
- Visualizações
- GitHub

## Resultado

Desenvolvimento de uma análise estruturada dos dados das empresas multimodais, com apresentação dos principais resultados encontrados.

## Fonte dos dados

Dados públicos relacionados às empresas habilitadas para o transporte multimodal.
