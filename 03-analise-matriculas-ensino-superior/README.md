# 03 — Análise de Matrículas do Ensino Superior

Análise de dados de matrículas do ensino superior utilizando ferramentas de Business Intelligence.

## Objetivo

Analisar a evolução e a distribuição das matrículas do ensino superior ao longo dos anos.

## Problema

Transformar dados educacionais em informações visuais que permitam identificar padrões e compreender a evolução das matrículas.

## Ferramentas

- Power BI
- DAX
- Dados públicos
- GitHub

## Resultado

Desenvolvimento de um dashboard interativo para análise dos dados de matrículas do ensino superior.

## Fonte dos dados

Instituto Nacional de Estudos e Pesquisas Educacionais Anísio Teixeira — INEP.
