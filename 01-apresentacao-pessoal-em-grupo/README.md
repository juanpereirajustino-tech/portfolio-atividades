# 01 — Apresentação Pessoal em Grupo

Esta atividade apresenta a participação no trabalho de apresentação pessoal em grupo.

## Objetivo

Apresentar os integrantes do grupo e organizar as informações solicitadas na atividade.

## Problema

Desenvolver uma apresentação organizada, permitindo apresentar as informações dos integrantes de forma clara e objetiva.

## Ferramentas

- Canva
- GitHub
- PDF

## Resultado

Apresentação pessoal desenvolvida em grupo e disponibilizada no GitHub.
