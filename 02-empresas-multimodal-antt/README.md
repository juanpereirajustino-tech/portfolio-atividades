# 02 — Empresas Multimodal — ANTT

Análise da base de dados de empresas com habilitação para atuar como Operador de Transporte Multimodal.

## Objetivo

Analisar informações sobre empresas habilitadas para o transporte multimodal.

## Problema

Transformar uma base de dados pública em informações que permitam compreender a distribuição e as características das empresas cadastradas.

## Ferramentas

- Excel
- CSV
- GitHub

## Resultado

Tratamento e análise dos dados, com elaboração de perguntas, respostas e visualizações para facilitar a interpretação das informações.

## Fonte dos dados

Agência Nacional de Transportes Terrestres — ANTT.
