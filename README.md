# 📊 Portfólio de Atividades Acadêmicas

## Sobre o projeto

Este repositório reúne as atividades acadêmicas desenvolvidas ao longo da disciplina, organizadas em um único espaço para facilitar a apresentação, consulta e avaliação dos trabalhos realizados.

As atividades envolvem apresentação, análise de dados, tratamento de bases, utilização de ferramentas de análise e visualização e organização de projetos utilizando o GitHub.

---

## 📚 Atividades

### 01 — Apresentação Pessoal em Grupo

Apresentação desenvolvida em grupo com o objetivo de apresentar os integrantes e organizar as informações solicitadas na atividade.

**Principais ferramentas:**
- Canva
- PDF
- GitHub

📁 [Acessar atividade](./01-apresentacao-pessoal-em-grupo)

---

### 02 — Empresas Multimodal — ANTT

Análise de uma base de dados pública relacionada às empresas habilitadas para atuar como Operador de Transporte Multimodal.

**Problema analisado:**

Transformar dados públicos em informações que permitam compreender a distribuição e as características das empresas cadastradas.

**Principais ferramentas:**
- Excel
- CSV
- Análise de dados
- GitHub

📁 [Acessar atividade](./02-empresas-multimodal-antt)

---

### 03 — Análise de Matrículas do Ensino Superior

Projeto de análise de dados de matrículas do ensino superior, utilizando ferramentas de Business Intelligence.

**Problema analisado:**

Transformar dados educacionais em informações visuais que permitam compreender a evolução e a distribuição das matrículas.

**Principais ferramentas:**
- Power BI
- DAX
- CSV
- GitHub

📁 [Acessar atividade](./03-analise-matriculas-ensino-superior)

---

### 04 — Análise de Empresas Multimodais

Projeto voltado à análise e interpretação de dados relacionados às empresas habilitadas para atuar no transporte multimodal.

**Problema analisado:**

Organizar e interpretar os dados disponíveis, transformando registros em informações que possam apoiar a análise e a tomada de conhecimento sobre o setor.

**Principais ferramentas:**
- Excel
- Análise de dados
- Visualizações
- GitHub

📁 [Acessar atividade](./04-analise-empresas-multimodais)

---

# 🛠️ Ferramentas utilizadas

Ao longo das atividades foram utilizadas diferentes ferramentas e tecnologias:

- **GitHub** — organização e versionamento dos projetos
- **Excel** — tratamento e análise de dados
- **Power BI** — criação de dashboards e visualizações
- **DAX** — criação de medidas e análises no Power BI
- **CSV** — armazenamento e manipulação de dados
- **Canva** — criação de apresentações

---

# 🎯 Objetivo do portfólio

O objetivo deste repositório é centralizar as atividades desenvolvidas durante a disciplina, demonstrando não apenas os resultados obtidos, mas também a capacidade de:

- organizar projetos;
- trabalhar com dados;
- realizar análises;
- utilizar ferramentas de tecnologia;
- criar visualizações;
- documentar projetos;
- utilizar o GitHub como ferramenta de organização e apresentação.
